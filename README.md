# 🍽️ Nosh: Malaysian Cuisine Guide

A front-end web application dedicated to exploring the rich and diverse culinary heritage of Malaysia. This interactive guide breaks down local delicacies and must-try dishes from every single state across the country, from Penang's street food to Sarawak's regional specialties.

## ✨ Features

- **State-by-State Navigation:** Explore curated lists of famous dishes categorized by all 13 states and 3 federal territories.
- **Interactive UI:** Smooth navigation and interactive elements to discover food origins and descriptions.
- **Responsive Design:** Fully accessible and visually appealing on both desktop and mobile devices.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and content routing.
- **CSS3:** Custom styling, flexbox/grid layouts, and visual presentation.
- **JavaScript (Vanilla):** Dynamic rendering and user interactions.

## 🚀 Getting Started

To run this project locally on your machine:

### Prerequisites
- A code editor like [Visual Studio Code](https://code.visualstudio.com/)[cite: 1]
- A modern web browser

### Local Setup
1. Clone the repository:
   ```bash
   git clone [https://github.com/yycapalot/Nosh-website.git](https://github.com/yycapalot/Nosh-website.git)
   ```
2. Navigate into the project directory:
   ```bash
   cd Nosh-website
   ```
3. Open the folder in your code editor.
4. Launch the Main.html file in your browser. If using VS Code, use the Live Server extension for real-time reloading.
